# Security Policy

## Supported versions

Security fixes are provided for the latest development version of ModelProbe.

## Reporting a vulnerability

Please do **not** report vulnerabilities through public issues or include credentials in any report.

Report the issue privately to the repository maintainer. Include:

- a clear description of the issue;
- steps to reproduce it;
- affected version and operating system;
- potential impact; and
- a suggested remediation, if available.

You should receive an acknowledgement within seven days. API keys and endpoint URLs must be redacted from all reports.
